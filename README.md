# Aquadesk

バージョン 1.0.1 ・ [変更履歴](CHANGELOG.md)

macOS のデスクトップに置く、水槽のようなウィジェットです。AI の使用量、マシンの状態、予定、メディア操作、ランチャーを 1 枚にまとめて表示します。

背景は水槽になっていて、水位はメモリの使用率、泡の量は CPU の負荷に合わせて変わります。魚が泳ぎ、底には砂と水草があります。

Swift 1 ファイル（AppKit + SwiftUI）で、Xcode プロジェクトなしで手元でビルドしてインストールします。

## できること

- **マシンの状態**: CPU / GPU 使用率、メモリ、起動後のディスク読み書き量
- **AI の使用量**: Codex の使用量、Claude の使用量（後述の注意あり）、作業中のアニメーション表示
- **メール**: Mail.app の未読数
- **予定・リマインダー**: これからの予定と未完了のリマインダー
- **メディア**: Spotify と Chrome 上のストリーミングサイト（YouTube ほか）の再生情報と操作、再生音に連動するビジュアライザー
- **外部ストレージ**: 接続中のドライブの容量と取り出し
- **Wi-Fi / Bluetooth**: ネットワーク名と接続中のデバイス
- **ショートカット**: アプリ・ファイル・URL・ショートカット.app・まとめて開くセットを登録できるタイル。円形に展開する入れ子のランチャー、ドラッグでの並べ替えに対応
- **ホットキー**: カーソル位置に全タイルのリングを表示し、押したままはじいて起動（既定 ⌃⌥Space）
- **レイアウト**: 縦向き / 横向き（縦長の画面向け）、画面いっぱいへの拡大、パネルの並び替えと幅・表示件数の変更
- 位置の固定、高さの固定（はみ出した分はスクロール）、ログイン時の自動起動

## 必要なもの

- macOS 14.2 以降（開発・確認は macOS 27）
- Xcode Command Line Tools（`xcode-select --install`）

## インストール

```bash
git clone https://github.com/84jtt4qnsr-maker/Aquadesk.git
cd Aquadesk
zsh install.sh
```

`~/Applications/Aquadesk.app` にビルドして起動します。初回起動時にログイン項目へ登録されます（メニューから外せます）。

ビルドだけしたい場合は `zsh build.sh` で、同じフォルダに `Aquadesk.app` ができます。

アップデートは `git pull` してから、もう一度 `zsh install.sh` を実行してください。

> 手元で簡易署名（ad-hoc）してビルドするため、ビルドし直すと macOS の権限確認が再度表示されることがあります。

## 設定と操作

メニューバーのアイコンから操作します。メニューの一番上に、今のバージョンが表示されます。

- 今すぐ更新
- ランチャーのホットキー
- 画面いっぱいに拡大（表示中のディスプレイに合わせて列を組み直して拡大）
- ウィジェットの向き（縦向き / 横向き）
- ウィジェットの高さ（内容に合わせる / 今の高さで固定、縦向きのみ）
- レイアウトを編集 / レイアウトを元に戻す
- 位置を固定
- Claude使用量をAPIで取得（既定はオフ）
- ログイン時に起動

位置の固定を外している間は、ウィジェットをドラッグで移動、下端（横向きでは右端）のドラッグで高さ（幅）を変更、タイルのドラッグで並べ替えができます。

「レイアウトを編集」中は、パネルをドラッグして並び替えられます。横向きではカードの間のつまみで幅を、縦向きでは −／＋ で予定などの表示件数を変えられます。並びと大きさは向きごとに保存されます。

## 権限とプライバシー

機能ごとに macOS の許可を求めます。許可しなかった機能はその欄が表示されないか、案内が出るだけで、ほかの機能は使えます。

| 権限 | 用途 |
| --- | --- |
| オートメーション（Mail / Spotify / Chrome） | 未読数の取得、再生情報の取得と操作 |
| カレンダー / リマインダー | 予定と未完了リマインダーの表示 |
| 位置情報 | Wi-Fi のネットワーク名の取得のみ（現在地は使いません） |
| システムオーディオ録音 | ビジュアライザー用。音はメモリ上で分析するだけで、保存も送信もしません |

- メール本文、予定のタイトル、Wi-Fi 名、再生中のタイトルやタブの URL は保存も外部送信もしません。
- Chrome では、登録済みのストリーミングサイトのタブにだけ JavaScript を実行します。Chrome の「表示 › デベロッパー › Apple Events からの JavaScript を許可」をオンにすると使えます。

### Claude の使用量について

既定では、Claude デスクトップアプリが手元に残す使用履歴だけを読みます。

メニューの「Claude使用量をAPIで取得」をオンにすると、Claude Code のログイン情報をキーチェーンから読み、Anthropic のサーバーに使用量を問い合わせます。

- この問い合わせ先は**公式に公開された API ではありません**。予告なく使えなくなる可能性があり、利用は自己責任でお願いします。
- ログイン情報は Anthropic への問い合わせにだけ使い、ほかへは送りません。トークンの更新もしません（Claude Code 自身のログインに影響しないため）。

Codex の使用量は、Codex が手元に残すログと、インストール済みの `codex app-server` への問い合わせから読みます。ログインは Codex 自身が扱い、このウィジェットは Codex のログイン情報を読みません。
